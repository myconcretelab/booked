# Polices des cartes postales

Les fichiers sont hébergés avec le plugin, sans appel à un service de polices externe.

- `italiana-latin.woff2` : [Italiana, Google Fonts](https://fonts.google.com/specimen/Italiana), licence SIL Open Font License dans `italiana-OFL.txt`.
- `bodoni-moda-latin.woff2` : [Bodoni Moda, Google Fonts](https://fonts.google.com/specimen/Bodoni+Moda), licence SIL Open Font License dans `bodonimoda-OFL.txt`.
- `QuillPaperScript.woff2` : fichier fourni par le propriétaire du site pour les messages manuscrits.
